# PokerToolBox ♠

Website: https://xfortuune.github.io/pokertoolbox/ · planned domain: **pokertoolbox.com**

A hub of Texas Hold'em practice tools, in **English** (default) and **Spanish**: the EN/ES
switch at the top right changes the whole site and the choice is remembered.

## 01 · Read the Board

A trainer for beginners. Each round deals 2 hole cards and a flop, and you answer:

1. **Board texture**: Extremely coordinated / Coordinated / Semi-coordinated / Dry
2. **Hand strength**: Very strong / Strong / Medium / Weak / Nothing

Each answer is graded and explained following the EducaPoker method (see **Rules** in the app).

- Four-colour deck (♠ black, ♥ red, ♦ blue, ♣ green).
- Explanations generated by the logic (category + reason).
- Score with correct answers, misses, % and streak, stored in `localStorage`.
- **Extremely coordinated** on the flop: monotone with a possible straight (e.g. 6♠7♠8♠). See `NOTES.md`.
- **Balanced mode**: deals coordinated, semi-coordinated and dry flops in equal shares, and
  extremely coordinated ones 10% of the time.
- Shortcut: `Enter` or `Space` to check / deal the next hand.

## 02 · Calculator

Equity calculator for up to 10 players: pick each player's cards and the board (cards you leave
empty are dealt at random) and see each player's win %, tie % and equity, plus the odds of
ending with each hand. Exact when few combinations remain (flop, turn) and Monte Carlo
(40,000 simulations) otherwise, in a Web Worker so the UI never blocks.

## 03 · Outs

Outs trainer: deals a hand with a draw (or overcards, a pair…) on the flop or the turn and asks
how many outs you have and your odds of hitting with the rule of 2 and 4. After checking it
shows the outs grouped by hand, a map of the 52 cards and the exact %. Rules in `NOTES.md`.

## 04 · Hand Review

Paste a Winamax hand — the replayer link or the hand history text (as PokerTracker shows it) —
and get, for each of Hero's decisions, the pot, pot odds, SPR and equity (vs random hands and vs
the cards shown at showdown). For now: Winamax No-Limit Hold'em cash games only.

- **Replayer links**: the hand is downloaded from Winamax's public JSON
  (`poker-assets.winamax.es/replayer/hand/…`), which allows cross-origin requests.
- **AI review**: for now the tool builds a ready-to-paste prompt for Claude or ChatGPT, with
  opponents' names replaced by their positions. Automatic analysis (a small server holding an
  API key) is planned.

## 06 · Glossary

380 poker terms collected from the
[Poker Red](https://www.poker-red.com/aprender-poker/diccionario-de-poker) and
[ZerosPoker](https://zerospoker.com/glosario/) glossaries, deduplicated, with original
definitions in both languages. Search works across both languages, without accents.

## Development

```bash
npm install
npm run dev      # dev server
npm test         # logic tests (Vitest)
npm run build    # production build in dist/
```

Every push to `main` runs the tests and deploys to GitHub Pages (`.github/workflows/deploy.yml`).

## Structure

- `src/logic/` — pure poker logic, no UI:
  - `cards.ts` — cards, deck, parsing.
  - `coordination.ts` — flop texture (ready to be extended to the turn).
  - `strength.ts` — hand strength.
  - `deal.ts` — random and balanced dealing.
  - `equity.ts` — hand evaluator and equity calculation.
  - `outs.ts` — counting outs, rule of 2 and 4, and dealing spots.
  - `hand-history.ts`, `winamax.ts` — hand history model and Winamax parsers (text, replayer JSON, links).
  - `hand-analysis.ts` — positions, pot odds, SPR and equity per decision, and the AI prompt.
  - `fixtures/` — anonymised sample hands for the tests.
  - `*.test.ts` — tests.
- `src/glossary/` — glossary terms (EN + ES), search and term of the day.
- `src/i18n/` — interface language (context, stored in localStorage). Each screen keeps its own
  `en`/`es` texts; the logic receives the language to word its explanations.
- `src/pages/` — home page (hub) and glossary page.
- `src/router.ts` — minimal hash router, with redirects from the old Spanish routes.
- `src/tools/registry.ts` — list of hub tools.
- `src/tools/read-the-board/`, `src/tools/calculator/`, `src/tools/outs/`, `src/tools/hand-review/` — tool UIs.
- `src/components/` — shared components (cards, header, trainer pieces, language switch).
- `src/lib/` — shared score storage and the migration of old localStorage keys.
- `NOTES.md` — cases the rules do not cover clearly and the provisional decisions taken.

Stack: Vite + React + TypeScript + Tailwind CSS. No backend.
